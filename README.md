I built a simple to-do list web app using HTML, CSS, and vanilla JavaScript. In the HTML file, I created the page structure with an input box, an Add button, and an empty list to hold the tasks. In the CSS file, I styled the layout, colors, buttons, and the strikethrough style for completed tasks. In the JavaScript file, I selected the elements using getElementById, added event listeners to the Add button and the Enter key, and created new list items dynamically with createElement and appendChild. Clicking a task toggles a "completed" class to mark it done, and a Delete button on each task removes it from the list. The page updates instantly without reloading. I tested adding, completing, and deleting tasks using Live Server in VS Code. Through this task, I learned about DOM manipulation, event handling, and updating the UI dynamically with JavaScript.
